# 🌐 İlk Web Sitem

HTML, CSS ve JavaScript kullanarak geliştirdiğim kişisel web projem. Bu proje, web geliştirme alanında öğrendiğim temel konuları uygulamak ve pratik yapmak amacıyla hazırlanmıştır.

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript (ES6+)
- Git ve GitHub

## ✨ Özellikler

- Kişisel tanıtım alanı
- Görsel kullanımı
- Etkileşimli butonlar
- JavaScript uygulamaları
- API üzerinden kullanıcı verilerini listeleme
- Asenkron JavaScript işlemleri (Fetch API, async/await)
- Responsive tasarım

## 🚀 Canlı Demo

[İlk Web Sitemi Görüntüle](https://zehraaydinn.github.io/ilk-web-sitem/)

## 💻 Projeyi Yerel Ortamda Çalıştırma

1. Depoyu bilgisayarına klonla:

   ```bash
   git clone https://github.com/ZehraAydinn/ilk-web-sitem.git
   ```

2. Proje klasörüne gir:

   ```bash
   cd ilk-web-sitem
   ```

3. `index.html` dosyasını tarayıcıda aç.

## 📚 Proje Hakkında

Bu proje, HTML, CSS, JavaScript ve Git/GitHub konularında öğrendiklerimi pekiştirmek için geliştirilmiştir. Web geliştirme yolculuğum boyunca yeni özellikler ekleyerek geliştirmeye devam edeceğim.
