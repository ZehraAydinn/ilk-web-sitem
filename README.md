# İlk Web Sitem

HTML, CSS ve JavaScript kullanarak geliştirdiğim kişisel web projem.

## Kullanılan Teknolojiler
- HTML
- CSS
- JavaScript

## Özellikler
- Kişisel tanıtım alanı
- Görsel kullanımı
- Etkileşimli butonlar
- JavaScript uygulamaları
- API üzerinden kullanıcı verilerini listeleme
